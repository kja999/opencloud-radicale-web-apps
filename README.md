This code generates dist which should be copied to apps folder for Opencloud.
It assumes opencloud 6.2.0 (module federation changed) with radicale installed.
radicale is proxied through opencloud

Gives 2 menu options in Opencloud to launch web apps; My Calendar, My Contacts

File web-app-radicale.tar.gz is the compiled version to copy and extract on the server
